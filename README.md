# La classe de maîtresse Coco

Site pédagogique bilingue français/anglais pour la classe de CE2A, école Frédéric-Louis Dorbritz (Nouvelle-Calédonie).

Site statique (HTML, CSS, JavaScript), sans compte élève et sans collecte de données. Le navigateur garde seulement la langue choisie et les activités terminées.

**État actuel : aperçu en ligne avant la publication finale.** Le site n'est pas encore annoncé aux élèves ; il demande aux moteurs de recherche de ne pas l'indexer (`robots.txt`, balise `noindex`).

- `index.html` : point d'entrée.
- `css/coco.css` : la charte graphique (couleurs, typographie, composants).
- `css/site.css` : la mise en page du site.
- `js/contenu.js` : matières et séquences.
- `js/problemes.js` : les problèmes ouverts (démarche de Sullivan & Lilburn). Ceux de la période 5 sont repris de l'outil d'une collègue, avec son accord.
- `js/banque.js` : la banque de problèmes.
- `js/app.js` : navigation et activités.
- `img/` : personnages et pictogrammes de l'enseignante.
- `fonts/` : police des titres (KG Red Hands, licence vérifiée par l'enseignante).

Le code source de travail est tenu dans un dépôt privé ; ce dépôt-ci reçoit seulement les versions à mettre en ligne.
